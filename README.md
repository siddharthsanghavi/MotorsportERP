# MotorsportERP

ERP for tracking parts on a FSAE Formula car.

## Web app MVP

This repository now includes a lightweight web app for FSAE teams to track car and inventory parts.

### Features

- Add parts with name, subsystem, quantity, location, and status
- Search parts by name, subsystem, location, or status
- Advance part status through a simple lifecycle
- Delete parts from tracking
- Browser `localStorage` persistence (no backend setup required)

### Run locally

Open the app in a browser:

- `index.html`

For best compatibility, you can also serve the folder with any static file server.
